# The Occupiable Videoboard: a screen you can stand inside

**Philadelphia Eagles · Lincoln Financial Field renovation · HKS Concept Pricing Package (Oct 22, 2026)**
**Prompt 4: the showpiece animation** (≈90 s, 16:9, 1920 × 1080, 60 fps)

It is a real-time Three.js piece that also renders frame-exact to MP4. The arc: the old
board is a billboard; the new board is drawn from its 16:9 canvas into a volume; then its
skins, its place in the bowl and the ribbon network; then the camera passes through the
pixels into the club; then a touchdown, felt from inside and outside at once.

Everything on screen that is a number comes from `src/data.js`, and every entry there
cites its page in `reference/20261022_LFF_Eagles_HKS.pdf`. Page usage and the
discrepancies found in the deck are logged in **[REFERENCE_NOTES.md](REFERENCE_NOTES.md)**.

## Run it

```bash
npm install
npm run dev          # http://127.0.0.1:5173
npm test             # geometry / ribbon unit tests (vitest)
```

| Key | Action |
|---|---|
| `Space` | play / pause |
| `←` / `→` | −5 s / +5 s |
| `R` | restart |
| `1` `2` `3` | **live skin options for Q&A**: all clear LED / hybrid / all traditional (strip wipe) |
| `0` | hand the skins back to the timeline |
| `Q` | quality toggle: strip pitch 1' → 2', MSAA, AO samples and resolution, shadows, pixel ratio. Remembered per browser. |
| `H` | hide the dev bar |

URL options: `?t=55` start time · `?paused` · `?q=low` · `?record=1` (manual clock for capture).

## Render the film

```bash
npm run record                 # → out/04_occupiable_videoboard_1080p60.mp4
npm run record:4k              # → out/04_occupiable_videoboard_2160p60.mp4 (DPR 2, same layout)
scripts/record-loop.sh --workers 2     # long captures: resumes after any crash, then encodes
npm run audio                  # soundtrack only → out/04_occupiable_videoboard_audio.wav
```

The recorder opens `?record=1` in headless Chromium through Playwright. It drives the
GSAP master timeline from a manual clock (`window.__renderAt(t)`) and writes JPEG frames.
Re-running skips frames already on disk. ffmpeg then encodes them with the offline
soundtrack. Options: `--from/--to` (seconds), `--fps`, `--workers`, `--msaa`, `--keep`,
`--frames-only`.

Rendering needs Playwright (`npm i -D playwright` or a global install) and ffmpeg. On a
machine without a GPU, Chromium falls back to SwiftShader: expect ≈4–6 s per 1080p frame.
On a machine with a GPU, set `GPU=1` to use it.

## QA

```bash
npm run rasterize   # reference/pages/p-NNN.png at 200 DPI (needs poppler's pdftoppm)
npm run fit         # re-solve the two volumes from the p67 / p68 face areas
node scripts/fit-cameras.mjs   # solve the p70 / p71 / p63 cameras from measured corners
npm run qa          # → qa/p63|p70|p71_overlay.jpg + _side.jpg (needs ImageMagick)
```

- **Unit tests** (`test/`). The face is exactly 214 × 109.5 with a 164 × 92.25 canvas, 25'
  wings and a 17'-3" band; 15,129 + 8,304 = 23,433 SF. All 12 face areas of both volumes
  match p67 / p68 within 1 SF. The field face stays an exact rectangle. The top is larger
  than the bottom (the p63 flare). The ribbon runs are modelled at their p69 linear feet
  within 1 LF. The totals land on 224,274.
- **Overlays** (`qa/`). Each overlay blends the render with its deck page. Red marks the
  deck corners and green the model's. p70: 5.5 px RMS. p63: 26 px on its panel. p71: 45 px,
  because p71's board is a 2D sketch rather than a true perspective (see notes).
- **Pass-through.** Scene 5 is one keyframed spline with a monotone time map, so there are
  no cuts. At the face the camera's path runs along x = 0, which is the centre of a gap
  between bars. The bars are real 3D instanced strips there, and the curtain wall has an
  open central bay, so nothing clips.

## How it is built

```
src/
  data.js              every figure, with page citations
  geometry/face.js     the face from its numbers (pure, tested)
  geometry/volume.js   faceted hexahedron + Levenberg–Marquardt fit to the face areas
  geometry/volumeParams.js  solved shapes (generated by npm run fit)
  materials/led.js     clear / traditional LED skin shader + InstancedMesh strips
  content/content.js   ContentTexture: one render target sampled by every face
  world/               stadium massing, ring paths, volumes, club interior, ribbons, sky/lights
  scenes/drafting.js   Scene 2 drafting field: draw-on face, extrusion, box net
  timeline.js          GSAP master timeline + per-frame state → world/HUD mapping
  hud.js               DOM/SVG overlay: dimension strings, counters, cards, labels, waveform
  post.js              N8AO · LED-only bloom · DOF · chromatic aberration · AgX · split render pass
  audio/               shared crowd envelope + live WebAudio playback
scripts/               record, audio, fit, QA, dev screenshots
```

- **Clear LED.** The skin shader draws emissive vertical bars at a 1' pitch (0.4' real
  pitch scaled ×2.5 for readability) with 40% fill, so it is 60% open. Coverage is
  filtered analytically with `fwidth`. Up close each bar and its LED pixels resolve, with
  true transparency between bars. Once bars fall under a few pixels, the skin resolves
  into the image: black content stays see-through, as on real transparent LED. Seen from
  behind, the bars are dark with a faint mirrored image, so the field shows through the
  veil. For the pass-through the north face also has a real `InstancedMesh` of 0.3'-deep
  bars, which crossfades with the shader skin by camera distance.
- **Traditional LED.** An opaque emissive panel whose 2' module grid fades in only at
  close range.
- **Skin changes.** These are a strip-by-strip vertical wipe with a bright switching
  front, never a crossfade. Keys `1/2/3` run the same wipe live.
- **Content.** Procedural GLSL only: abstract feather streaks in midnight green, teal and
  silver (the p34 language), the p4 waveform, the touchdown burst and big type. No marks.
- **Bloom.** Only LED emission is authored above 1.0 in linear HDR, so the
  luminance-gated bloom is effectively selective to the LED surfaces and ribbons. A
  separate selective pass would mean another full scene render.
- **Volumes.** The deck gives six face areas and a depth per board. The field face is held
  at exactly 214' × 109.5'. The front tilt and underside slope are read off the
  p51 / p53 sections. The other six shape parameters are solved so every face area matches
  the deck within 1 SF. Details and the depth trade-off are in REFERENCE_NOTES.md.

## Storyboard as built

| Time | Scene |
|---|---|
| 0:00–0:08 | **The billboard.** Night, the south end zone. The existing board on its lattice tower plays, flickers and powers down. *A screen you watch. · A building you enter.* The dashed p4 TODAY line crosses the dark. |
| 0:08–0:24 | **Drawing the board.** The 164' × 92'-3" canvas is drawn (15,129 SF), then the 25' wings (214') and the 17'-3" band (109'-6", 23,433 SF). It extrudes 155' and unfolds as a box net with all six p67 areas, then folds back. The south volume extrudes 109' with its p68 areas. Both fly into the p66 massing axon and the counter lands on **224,274 SF**. |
| 0:24–0:38.5 | **Three skins.** The p70 frame and option card: Option 1 → 2 → 3 at 3.5 s each, by strip wipe. Then the p71 south beat (4 s). |
| 0:38.5–0:46 | **The network.** The p67 / p69 bowl axon. Teal volumes glow and the eight ribbon runs chase around the bowl with their LF labels. |
| 0:46–1:06 | **Through the pixels.** One unbroken move from midfield into the north board: the image resolves into bars (DOF, CA ≤ 0.6 px), the camera passes between them, turns to see the field through the veil, and enters the club (p97–99). It rises through a section cut past each labelled floor, then drops to the super vom at the main concourse (p51, p87). |
| 1:06–1:22 | **Touchdown.** Night, split by a 2 px line: outside (bowl, plaza face lighting the plaza) and inside (the veil floods, figures raise their arms). One crowd envelope drives both halves, the ribbon whip and the p4 waveform jump. |
| 1:22–1:30 | **Close.** The split slides away and the camera returns to the p70 frame, with the board at rest and glowing teal. *The first occupiable videoboard in the NFL.* (PROPOSED COPY; the claim must be verified by HKS before the presentation.) |

Scene 3 is longer than the storyboard's 12 s so that it can hold 3 × 3.5 s plus the 4 s
south beat. Scene 4 absorbs the difference.
