# Seating Bowl — Closer, Louder, More Premium

A 94-second, 16:9, 1920 × 1080 / 60 fps data-driven film. It explains the seating-bowl moves of the Lincoln Financial Field renovation in the HKS Concept Pricing Package (Oct 22 2026). Every figure on screen is copied verbatim from the deck into `src/data.js`, with page citations. Discrepancies between pages are logged in [`REFERENCE_NOTES.md`](REFERENCE_NOTES.md).

Built with Vite + Three.js (r180), a GSAP 3 master timeline on a manual clock, and `postprocessing` (N8AO ambient occlusion, selective bloom on the LED ribbon boards only, subtle depth of field, MSAA). An SVG overlay draws the 2D sections and data on the same timeline.

## Run

```bash
npm install
npm run prep        # rasterize the deck pages (200 DPI) -> reference/pages/, cut the p36 texture
npm run dev         # http://localhost:5173
```

| Key | Action |
|---|---|
| `Space` | pause / play |
| `←` / `→` | previous / next scene |
| `R` | restart |

URL flags:

- `?t=46` starts at a given second.
- `?paused=1` starts paused.
- `?qa=56` overlays reference page 56 at 50 % (dev server only).
- `?record=1` turns on deterministic frame stepping through `window.__film`.

## Render

```bash
npm run record      # out/02_seating_bowl_1080p60.mp4
npm run record:4k   # out/02_seating_bowl_2160p60.mp4 (deviceScaleFactor 2)
node scripts/record.mjs --from 20 --to 32 --keep     # partial range, keep PNG frames
node scripts/record.mjs --scale 0.5 --fps 30         # quick 540p30 preview
```

The record script builds the app, serves `dist/` and drives headless Chromium with Playwright. It steps each frame with `window.__film.renderTime(f / fps)`, captures a PNG, then encodes H.264 with ffmpeg. Rendering is deterministic: every tween, counter, camera move, crowd wave and dust particle is a pure function of film time.

- Playwright is resolved from the project or from a global install; if it is missing, run `npm i -D playwright && npx playwright install chromium`.
- `RECORD_SWIFTSHADER=1` forces software WebGL for machines without a GPU. It is correct but slow, roughly 3–10 s per 1080p frame in the 3D scenes.
- Add `--resume` to continue an interrupted render.

`npm run qa` writes camera-match overlays for the four seat views and a keyframe contact sheet to `qa/`.

## Layout

```
src/data.js             every on-screen figure, with page citations
src/palette.js          deck colours (existing red, new greens, glass teal, tiers)
src/geometry/*.json     traced plan rings and sections (generated by tools/build_geometry.mjs)
src/three/              bowl sweep (rings, tiers), field, crowd, plan graphics, ladder, dust
src/overlay/svg.js      SVG helpers: drawable strokes, counters, numbered dots
src/scenes/s1…s9        one module per scene: build(tl) + frame(t)
scripts/                record, qa, dev shots
tools/                  page rasterization, gridded crops, geometry tracing
```
